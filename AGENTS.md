# Project Instructions

## Project

This is a simple Book Library REST API built with Node.js and Express.

## General Rules

- Keep the implementation simple.
- Use JavaScript.
- Use Express for the API.
- Store data in memory for now.
- Do not add a database unless the plan specifically requires it.
- Keep the existing project structure.
- Do not modify files unrelated to the requested feature.

## Testing

- Use Jest and Supertest for API tests.
- Tests should be written before implementation when implementing a plan.
- Run `npm test` after completing each task.

## API

- Use REST-style endpoints.
- Return JSON responses.
- Use appropriate HTTP status codes.
- Keep endpoint behavior consistent with the existing API.

## Implementation

- Follow the implementation plan exactly.
- Do not add extra features.
- If the plan is unclear or incorrect, stop and explain the problem.
